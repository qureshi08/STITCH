# STITCH OS | Maryam Shahid Studio

STITCH OS is a production-grade Operating System designed for high-end fashion lifecycle management. It bridges the gap between creative design (PLM) and business operations (Finance & Logistics).

## 🧩 Core Modules

### 1. **Industry-Grade Security & Auth**
- **Server-Side Protection**: Deterministic role-based access control (RBAC) powered by Next.js Middleware and Supabase SSR.
- **Role Isolation**: Strict boundaries between `ADMIN` (Studio Staff) and `CLIENT` (Brand Owners) portals.
- **Session Persistence**: Robust cookie-based session management that prevents UI flickering and ensures a stable experience across devices.

### 2. **Admin Command Center**
- **Business KPIs**: Real-time tracking of Active Projects, Studio Earnings (YTD), and Outstanding Client Ledgers.
- **Workflow Orchestration**: Direct oversight of all active collections and production batches.

### 3. **Client Portal**
- **Transparency**: Clients get a premium window into their production lifecycle.
- **Timeline Tracking**: Visual progress indicators for every piece in their collection.
- **Financial Overview**: Instant access to pending invoices and payment history.

### 4. **Technical PLM (Product Lifecycle Management)**
- **9-Stage Workflow**: Standardized technical pipeline:
  1. Illustration
  2. Pattern Making
  3. Tech Pack Generation
  4. Sampling
  5. Pre-Production
  6. Production
  7. Quality Control (QC)
  8. Packaging
  9. Delivery
- **SKU Management**: Unique ID generation and "Stage Locking" to prevent accidental state changes during production.

### 5. **Finance Hub**
- **Invoicing System**: Integrated milestone-based billing for both Clients and Vendors.
- **Ledger Management**: Global and project-specific financial health tracking.
- **Currency Support**: Multi-currency handling for international studio operations.

### 6. **Asset & Collaboration Engine**
- **File Gallery**: Centralized repository for technical sketches, fabric references, and production documents.
- **Real-Time Discussion**: Contextual comment threads on every project and garment for seamless studio-client communication.

### 7. **Premium Design Language**
- **Boutique Aesthetic**: A "minimal-premium" dark/beige theme inspired by luxury brand guidelines.
- **Ultra-Responsive**: Fully optimized for iPads and mobile devices, ensuring the studio can be managed on the go.
