# STITCH OS | Maryam Shahid Studio

STITCH OS is a proprietary, production-grade Operating System designed specifically for luxury fashion studios. It streamlines the entire lifecycle from creative technical design to financial logistics.

## 🚀 Live on Vercel
The application is integrated with Vercel for continuous deployment. Every push to the `master` branch triggers an automated build and deployment.

---

## 🏗️ Core Architecture
- **Framework**: Next.js 15 (App Router)
- **Database & Auth**: Supabase (PostgreSQL + SSR)
- **Styling**: Vanilla CSS with modern premium aesthetics
- **Security**: Deterministic Server-Side Role-Based Access Control (RBAC)

---

## ✨ Key Features

### 🔐 Multi-Portal Experience
- **Admin Command Center**: Real-time business KPIs, studio earnings tracking, and workflow orchestration.
- **Client Portal**: A premium, transparent window for brand owners to track their collection's production lifecycle.

### 🧵 Product Lifecycle Management (PLM)
- **Industrial Workflow**: Standardized 9-stage technical pipeline (Illustration → Pattern → ... → Delivered).
- **SKU Management**: Unique SKUs for every garment with "Stage Locking" for production integrity.
- **Timeline Tracking**: Visual progress indicators for every piece in a collection.

### 💰 Finance & Ledger Hub
- **Milestone Billing**: Automatic invoice generation based on project progress.
- **Dual Ledger**: Dedicated tracking for both Client Receivables and Vendor Payables.
- **Multi-Currency Support**: Native handling of various currencies for international operations.

### 🤝 Strategic Collaboration
- **Asset Engine**: Centralized repository for tech packs, fabric briefs, and sketches.
- **Contextual Discussions**: Real-time comment threads integrated into every project and SKU.
